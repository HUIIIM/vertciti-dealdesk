# ADR 0005：Bearer 令牌、只认请求头

- 状态：已采纳（2026-10-22）
- 决定：令牌放 `Authorization: Bearer`，前端存 sessionStorage（关标签即失效）；服务端**不读 cookie**，
  因此不存在 CSRF 面，也无需 CSRF token。令牌只存 sha256。错令牌按来源 IP 滑动窗口限流（429 + Retry-After）。
- 缺省 `DEALDESK_AUTH=off` 与 v1 单用户本机工具行为一致；多人使用时开启。
- 未做（已列入未决）：SSO / OIDC、令牌过期与轮换。
- 2026-10-23 补充：加 Google 登录（OIDC 授权码流程，邀请制：只认董事长登记过的邮箱）。登录换来的是会过期的会话令牌
  （`dds_`，只存 sha256，表 `user_sessions`），经 URL 片段交给前端，之后仍走 Bearer 头——服务端依旧不读业务 cookie，
  不引入 CSRF 面。OAuth 的 state / nonce 用只对 `/api/v2/auth` 生效的短期 HttpOnly cookie。配置见 `docs/GOOGLE-LOGIN.md`。
