# ADR 0005：Bearer 令牌、只认请求头

- 状态：已采纳（2026-10-22）
- 决定：令牌放 `Authorization: Bearer`，前端存 sessionStorage（关标签即失效）；服务端**不读 cookie**，
  因此不存在 CSRF 面，也无需 CSRF token。令牌只存 sha256。错令牌按来源 IP 滑动窗口限流（429 + Retry-After）。
- 缺省 `DEALDESK_AUTH=off` 与 v1 单用户本机工具行为一致；多人使用时开启。
- 未做（已列入未决）：SSO / OIDC、令牌过期与轮换。
- 2026-10-27 补充（消解批定版）：Google 登录走授权码流＋PKCE（S256），id_token 以 JWKS RS256 本地验签；
  准入＝邮箱与既有用户 username 匹配（大小写不敏感）且 active，不开放注册。登录签发服务端会话
  （`web_sessions` 表，只存 sha256、可吊销、30 天滑动续期），cookie `dd_session`（HttpOnly + Secure +
  SameSite=Lax）；cookie 身份的写请求另校验 Origin 同源。早期邀请制实现（`user_sessions`／片段回传令牌）
  已整套摘除，本条为准。
