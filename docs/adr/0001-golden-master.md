# ADR 0001：用金标准（golden master）锁定 v1 计算

- 状态：已采纳（2026-10-22）
- 背景：v2 要大规模重构（分层、换数据层、换前端），蓝图硬要求“计算结果与 v1 完全一致”。
- 决定：在重构前用 v1 代码录制两层输出——① 函数层：真实调用时捕获的 1,500+ 组参数及返回值；
  ② 接口层：API 矩阵回放（含 PDF 文本、xlsx 单元格、PNG 哈希）。时间戳、日期等不确定字段先归一化，
  网络调用全部拦截。`tests/test_golden_v1.py` 逐条比对，任何偏离即失败。
- 后果：重构可以大胆做；代价是改 v1 报告字节（哪怕折一行 CSS）也会被拦——这是有意的。
  确需改变 v1 输出时：在 v1 基线 worktree 重新录制，并在提交说明里写明原因。
