# 机构级承销引擎 · 方法论（cre-1.0）

> 适用：office / retail / industrial（按租约出租，`property_type = commercial`）与 multifamily（按户型，
> `property_type = multifamily`，见第 10 节）。两种物业共用债务、退出、收益、瀑布与导出。
> 代码：`app/domain/v2/cre/`；接口：`POST /api/v2/cre/run` 给完整结果（示例输入：`GET /api/v2/cre/example`）；
> 工作台按“机构级”赛道走统一的 `POST /api/v2/model/institutional`（指标口径与其他赛道一致，完整结果在 `detail.cre`）。
> 验证：`tests/test_cre_engine.py`（每条口径都有可手算的基准用例）。改任何口径，必须同时改本文与对应用例。

## 1. 时间约定
- 分析起点 = 交割月（第 0 月月初）。第 k 年 = 第 (k−1)×12 … k×12−1 月。
- 持有 N 年：在第 N×12−1 月月末出售。为算退出价，引擎多算一年（第 N+1 年）。
- 年度 IRR 用年度现金流；同时给出**按月现金流折算的年化 IRR**（更精确）。两者都报，不混用。

## 2. 租约与续租（Rent roll）
- 每份租约一条“租期段链”：已签约段 → 到期后按**市场租赁假设（MLA）**续上的假设段 → … 直到分析期结束。
- **续租与新租加权成一条路径**（Argus 默认口径），续租概率为 p：

| 项 | 口径 |
|---|---|
| 空置月 | (1−p) × 新租空置月，四舍五入到整月 |
| 免租月 | p × 续租免租 + (1−p) × 新租免租，四舍五入到整月 |
| TI | (p × 续租 TI + (1−p) × 新租 TI) × 面积，按金额加权、不取整 |
| LC | (p × 续租 LC% + (1−p) × 新租 LC%) × 新租期合同租金总额 |
| 新段租金 | 起租当月的市场租金；市场租金按分析年阶梯增长 |

- 租金递增：在每个**租约周年日**按递增率上调。已在执行的租约，分析起点的租金即当前合同租金。
- 免租：只免基本租金，费用回收照收。
- 未出租面积：视为“分析开始即到期、按新租招租”（续租概率为 0），先空置再起租，并计 TI / LC。
- 结果里的 `rent_roll` 列出每一段，`speculative = true` 表示该段是假设续上的，不是签约事实。

## 3. 收入
| 科目 | 口径 |
|---|---|
| 潜在租金 | 在租面积的合同租金 + 回收；空置面积按当月市场租金与 NNN 回收计应收 |
| 周转空置 | 两段之间空置期的应收（负数） |
| 免租 | 免租月的基本租金（负数） |
| 费用回收 | NNN：按面积占比分摊全部可回收费用；Gross：不回收；基年：只回收超过基年的部分（基年取租约约定，或分析首年） |
| 一般空置 | 一般空置率 × 潜在租金，**先扣除已建模的周转空置**，不低于 0（避免空置被重复扣） |
| 信用损失 | 信用损失率 × (基本租金 − 免租 + 回收 − 一般空置) |
| 有效总收入 EGR | 基本租金 − 免租 + 回收 − 一般空置 − 信用损失 |

## 4. 费用与资本支出
- 可回收与不可回收费用按 $/SF/年计，按分析年阶梯增长。
- 管理费 = 管理费率 × EGR，不回收。
- NOI = EGR − 运营费用。
- NOI 之下依次扣 TI、LC（在新段起租当月一次性计）、资本储备，得到**债前现金流**（无杠杆）。

## 5. 债务
- 贷款在交割时一次放款：贷款额直接填，或按 LTV × 收购价。开办费按贷款额的百分比计，在交割时支付。
- 只付息期内按余额付息；之后按剩余摊还月数计等额本息。
- 浮动利率 = min(SOFR, 利率上限) + 利差。SOFR 按分析年取曲线值，曲线最后一年向后沿用。利率变化时，按当期余额与剩余摊还月数重算月供。
- 退出时按当月月末余额偿清。
- 夹层（`mezz`）：交割时与优先贷款一起放款（金额或占收购价比例二选一），固定利率只付息，退出时偿清；开办费计入交割。
  DSCR 按优先 + 夹层合计还本付息计（股权视角，更保守），另报优先贷款单独的最小 DSCR；债务收益率只按优先贷款。
- 再融资（`refinance`，第 r 月）：价值 = 第 r … r+11 月 NOI 合计 ÷ 估值资本化率；
  新贷款 = min(LTV × 价值, NOI ÷ (最低 DSCR × 年还款常数), NOI ÷ 最低债务收益率)，年还款常数在只付息 ≥ 12 个月时取利率、
  否则取等额本息常数。第 r 月照旧还旧贷款，月末用新贷款偿清旧优先贷款余额（及夹层，可选），扣再融资费用，
  净额进当月股权现金流（为负 = 股权补钱）；新贷款从第 r+1 月起计息，退出时按其余额偿清。

## 6. 退出与收益
- 售价 = 第 N+1 年 NOI ÷ 退出资本化率，再扣卖方成本。
- 退出 NOI 口径（`exit_noi_basis`）：
  - `forward`（默认）：第 N+1 年 NOI 原值。
  - `stabilized`：该年按潜在收入收足（在租合同租金与回收、空置面积按市场应收），不计周转空置与免租，
    再按一般空置率、信用损失率、管理费率重算；费用照实际。用于退出年有租约周转、原值会压低售价的情形。
    稳定化不扣买方将承担的续租成本（空置、免租、TI / LC），偏乐观；投委会应同时看两种口径。
- 无杠杆现金流：第 0 期 −(收购价 + 交割成本)；各年为债前现金流；最后一年加上净售价。
- 有杠杆现金流：第 0 期 −(收购价 + 交割成本 + 开办费 − 贷款额)；各年为债前现金流 − 还本付息；最后一年加上净售价 − 贷款余额。
- 指标：

| 指标 | 定义 |
|---|---|
| 进入资本化率 | 首年 NOI ÷ 收购价 |
| 成本收益率 | 首年 NOI ÷ (收购价 + 交割成本) |
| IRR | 无杠杆 / 有杠杆，年度与按月年化各一 |
| 权益倍数 | 正现金流合计 ÷ 负现金流合计 |
| NPV | 按折现率折现 |
| DSCR | 当年 NOI ÷ 当年还本付息，给首年值与最小值 |
| 债务收益率 | 首年 NOI ÷ 贷款额 |
| 首年现金回报 | 首年有杠杆现金流 ÷ 股权 |

- IRR 在区间内无解时返回空，界面显示“—”，不编数。

## 7. 分配瀑布（GP / LP）
- 按 LP IRR 设门槛，逐期（年度）分配。门槛依次为：优先回报 < 第一档 < 第二档 …。
- 每个门槛维护一个账户，记 LP 还要拿多少才能达到这个 IRR：每期先按门槛利率复利，再加上 LP 本期出资。
- 本期可分配现金依次分配：
  1. 优先回报以内，按出资比例分；
  2. 之后每档按该档的 LP 份额分，直到 LP 达到下一门槛；
  3. 最后一档之上，按最终份额分。
- 每期分完后，各账户扣掉 LP 本期所得，扣到 0 为止，已达标的门槛不再回头。
- 负现金流（追加出资）由 LP / GP 按出资比例承担。
- GP 所得包含其跟投部分。promote = GP 所得 − GP 按出资比例本应得的部分。
- 按月（`frequency = monthly`）：用按月有杠杆现金流逐月分配，门槛是年化 IRR，按 (1 + h)^(1/12) − 1 折成月利率复利；
  报出的 LP / GP IRR 按月年化；表格里的年度 LP / GP 是按月分配的年度合计。
- GP catch-up（`catch_up_target_pct` = t、`catch_up_rate_pct` = c，须 c > t）：LP 达到优先回报后、进第一档之前，
  本期现金按 c 给 GP、1 − c 给 LP，直到 GP 累计利润（累计所得 − 累计出资）= t × 双方累计利润合计；按累计口径逐期判断。
- 回拨（`clawback`）：期末若 LP IRR 仍低于优先回报、GP 拿过 promote，GP 在最后一期退回 promote，最多退到 LP 恰好达到优先回报
  （缺口 = −Σ LP 净现金流 × (1 + 优先回报)^(期末 − t)）。
- IRR 多根：现金流多次变号（分配后又追加出资）时可能有多个 IRR，取离 10% 最近的那个根（与 Excel 默认一致）。

## 8. 本版不建模（已知局限，诚实列出）
- CPI 指数化递增、百分比租金（零售）、费用上限 / gross-up、单租户 / 多租户分别设定的 MLA（本版每栋一套 MLA）。
- 按概率分叉的续租树（本版是加权单路径，与 Argus 默认一致）。
- 瀑布是美式（逐期）分配；欧式（整只基金、先还全部本金）瀑布不在本版。
- 施工贷与开发项目的建设期；多次再融资（本版一次）；夹层的 PIK 计息。
- 退出价按第 N+1 年 NOI 计：若有租约在退出年周转，该年的周转空置与免租会压低售价（“退出年 NOI 失真”）。
  可改用稳定化口径（见第 6 节）；用原值时备忘录会在事实要点里标出这笔损失和对售价的影响；敏感性也可能因此不单调
  （空置月数推移到期时点，使周转落进或移出退出年）。
- 校验报错与导出文件（Excel、备忘录）目前只有中文；英文界面的翻译在下一阶段。

## 8.1 导出
- **承销模型 Excel**（`/api/v2/deals/{id}/export/model`）：假设 / 现金流 / 收益 / 租金表 / 月度 / 瀑布 / 说明。
  物业层科目与还本付息是引擎值（灰字），EGR、NOI、现金流、售价、IRR、倍数、NPV、资本化率、DSCR 是 Excel 公式；
  改“假设”页蓝字（收购价、交割成本、退出资本化率、卖方成本、折现率）即重算。“收益”页并列引擎结果供核对。
- **机构投委会备忘录 PDF**（`/api/v2/deals/{id}/export/memo`）：交易概要（关键指标、淘汰条件、事实要点）、
  租金表与到期分布、逐年现金流、资本结构 / 债务 / 退出、收益与 GP / LP 分配、敏感性（每格重跑引擎）、主要假设、方法与局限。
- 验证：`tests/test_cre_exports.py`——装有 LibreOffice 时真重算 Excel，逐项与引擎一致，并验证改退出资本化率后售价与 IRR 重算。

## 10. 多户公寓（按户型，`app/domain/v2/cre/multifamily.py`）
- 输入：户型表 `unit_mix`（户数、户均面积、在租月租、市场月租、翻新户数、每户翻新成本、翻新溢价）与 `multifamily` 假设；
  空置率与坏账沿用 `general_vacancy_pct` / `credit_loss_pct`，费用增长与管理费沿用 `opex.growth_pct` / `mgmt_fee_pct_egr`。

| 科目 | 口径 |
|---|---|
| 潜在租金 GPR | 全部户 × 当月市场月租（按分析年阶梯增长） |
| Loss-to-lease | 在租租约按租期 T 个月均匀到期：第 c 批在第 c 月月末到期，之后每 T 个月续一次，续约即调到当月市场租金；首次到期前按交割时在租租金收。GPR 与在租租金之差 |
| 翻新 | 按户型顺序、每月固定户数开工；停用期不收租（“翻新停用”），复租按市场月租 + 溢价（溢价随市场增长）；成本在开工当月计入 NOI 之下的资本支出 |
| 不产生租金的户 | 按各户型户数占比摊 |
| 在租租金 | = GPR + loss-to-lease + 翻新溢价 − 翻新停用 − 不产生租金（Excel 里是公式） |
| 优惠 / 空置 | 各按在租租金的百分比 |
| 其他收入 | 每户每月 × 在线产生租金户数 × (1 − 空置率)，单独增长率 |
| 坏账 | 坏账率 × (在租租金 − 优惠 − 空置 + 其他收入) |
| 费用 | 房产税与保险（全年金额）、每户运营费用、翻房成本（年换租率 × 在线户数 × 每次成本 ÷ 12），按费用增长率阶梯增长；管理费按有效总收入 |
| 稳定化退出 NOI | 加回退出年翻新停用损失，优惠、空置、坏账、管理费按同一费率重算；优惠是常态，不加回 |

- 简化（如实列出）：翻新后的户按当月租金计，不计续约滞后；续约一律调到市场租金（无涨幅上限、无租金管制）；不按户逐份租约。
- 验证：`tests/test_cre_multifamily.py`——闭式解（IRR = 资本化率）、loss-to-lease 消化（首年 11,350 / 户手算）、市场增长滞后、
  翻新停用 / 溢价 / 成本逐月手算、各项扣减与费用手算、稳定化加回、校验报错。
